# sh

As operações de shell dependem das permissões e do ambiente de hospedagem. Não disponibilize shell irrestrito a scripts não confiáveis.

## Funções expostas no código

- `sh.run`
- `sh.cd`
- `sh.pwd`
- `sh.env`
- `sh.which`

**Origem da lista:** [`crates/aipo-stdlib/src/sh.rs`](https://github.com/poppyTM/aipo-lang/blob/main/crates/aipo-stdlib/src/sh.rs), registro de funções nativas. Isto **não equivale a uma execução de testes** no commit atual.
