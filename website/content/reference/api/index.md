# APIs da biblioteca padrão

As referências estão agrupadas por módulo. Comece pelo [índice de biblioteca padrão](/reference/stdlib), que explica o objetivo de cada um, ou pelo [manual de uso](/manual/standard-library).

Consulte a navegação lateral para selecionar um módulo específico. Cada entrada mostra nomes efetivamente registrados no código Rust e um link para a implementação de origem. A existência de uma função não substitui um teste do backend que você vai utilizar.

[Ver todos os módulos](/reference/stdlib) · [Voltar ao manual](/manual/).
