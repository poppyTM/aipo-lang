# task

O dispatcher efetivo de tarefas é implementado pela VM; o módulo expõe nomes que a VM trata especialmente.

## Funções expostas no código

- `task.spawn`
- `task.sleep`
- `task.all`
- `task.race`
- `task.timeout`
- `task.cancel`
- `task.group`

**Origem da lista:** [`crates/aipo-stdlib/src/task.rs`](https://github.com/poppyTM/aipo-lang/blob/main/crates/aipo-stdlib/src/task.rs), registro de funções nativas. Isto **não equivale a uma execução de testes** no commit atual.
