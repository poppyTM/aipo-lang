# time

`time.now` e `time.monotonic` dependem da capability de relógio concedida pelo host.

## Funções expostas no código

- `time.now`
- `time.monotonic`
- `time.date`
- `time.time_of_day`
- `time.date_time`
- `time.parse_date`
- `time.parse_time`
- `time.parse_iso`
- `time.parse_datetime`
- `time.duration`
