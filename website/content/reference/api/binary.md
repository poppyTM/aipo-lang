# binary

Leituras e escritas em buffers exigem limites válidos. Funções incluem versões little-endian e big-endian.

## Funções expostas no código

- `binary.read_i8`
- `binary.read_u8`
- `binary.read_i16_le`
- `binary.read_i16_be`
- `binary.read_u16_le`
- `binary.read_u16_be`
- `binary.read_i32_le`
- `binary.read_i32_be`
- `binary.read_u32_le`
- `binary.read_u32_be`
- `binary.read_i64_le`
- `binary.read_i64_be`
- `binary.read_u64_le`
- `binary.read_u64_be`
- `binary.read_f32_le`
- `binary.read_f32_be`
- `binary.read_f64_le`
- `binary.read_f64_be`
- `binary.write_i8`
- `binary.write_u8`
- `binary.write_i16_le`
- `binary.write_i16_be`
- `binary.write_u16_le`
- `binary.write_u16_be`
- `binary.write_i32_le`
- `binary.write_i32_be`
- `binary.write_u32_le`
- `binary.write_u32_be`
- `binary.write_i64_le`
- `binary.write_i64_be`
- `binary.write_u64_le`
- `binary.write_u64_be`
- `binary.write_f32_le`
- `binary.write_f32_be`

- `binary.write_f64_be`
- `binary.read_varint`
- `binary.write_varint`
- `binary.slice`
