# fs

Este serviço pode exigir capability explícita no host: declarar uma função no esquema não concede permissão para utilizá-la.

## Inventário da implementação

- `fs.read_text`
- `fs.roots`

O inventário deriva de [`crates/aipo-stdlib/src/fs.rs`](https://github.com/poppyTM/aipo-lang/blob/main/crates/aipo-stdlib/src/fs.rs). Esta listagem não executa chamadas nem garante suporte entre backends.
