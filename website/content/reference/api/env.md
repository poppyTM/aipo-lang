# env

Este serviço pode exigir capability explícita no host: declarar uma função no esquema não concede permissão para utilizá-la.

## Inventário da implementação

- `env.get`
- `env.has`

O inventário deriva de [`crates/aipo-stdlib/src/env.rs`](https://github.com/poppyTM/aipo-lang/blob/main/crates/aipo-stdlib/src/env.rs). Esta listagem não executa chamadas nem garante suporte entre backends.
