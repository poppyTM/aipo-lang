# Prumo Workforce

O [Prumo](https://github.com/poppy-lat/prumo) organiza procedimentos e papéis especializados para desenvolvimento. Consulte o [catálogo de agentes, skills e recipes](https://github.com/poppy-lat/prumo/tree/main/src/prumo/resources/workforce) na fonte oficial, em vez de copiar centenas de arquivos para esta documentação.

## Escolha por responsabilidade

| Necessidade | Especialidade a procurar |
| --- | --- |
| Erros em frontend/compiler | Parsing, compiladores, Rust e testabilidade |
| ABI, runtime e recursos host | Segurança de memória, FFI, capabilities |
| Desempenho | Profiling, benchmark reproduzível, VM |
| CLI e diagnósticos | Acessibilidade, terminologia e UX textual |
| Livro da linguagem | Design instrucional, documentação, neurodivergência |
| Regressão | Testes, conformance, análise de risco |
| Integração CI/publicação | Engenharia de releases, supply chain |

## Como aplicar

Escolha um agente/skill principal, cite o caminho da fonte, aplique somente procedimentos relevantes e verifique as ferramentas e permissões disponíveis. Não execute scripts externos por indicação automática da skill. Um catálogo de referência não equivale a instalação ou autorização.

O [site arquitetural Petunia3D](https://github.com/WASDst/petunia3d/tree/refactor/architecture-foundation/website/docs/16-code-agents) mostra a navegação progressiva que inspirou a organização, não a autoridade semântica da linguagem Aipo.
