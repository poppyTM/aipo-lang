# Protocolo para agentes

Os agentes devem ler **o menor contexto suficiente**, não carregar todos os documentos e skills. O sistema de documentação é orientação operacional; não autoriza ações perigosas ou declara funcionalidades implementadas.

## Entrada obrigatória por tarefa

1. [Como ler e encontrar a fonte certa](/engineering/agents/reading).
2. [Fluxo de implementação e evidências](/engineering/agents/workflows).
3. Capítulo de [engenharia](/engineering/) do domínio afetado.
4. Código e testes concretos no commit/branch.
5. Skills Prumo especializadas **apenas se forem pertinentes**.
