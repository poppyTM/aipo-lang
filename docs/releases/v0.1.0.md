# Aipo v0.1.0

**Data:** 2026-10-28 · **Goal:** P07-G03 · **Status:** publicado como estável

Release: https://github.com/poppyTM/aipo-lang/releases/tag/v0.1.0 · Evidência: [P07-G03](../evidence/P07-G03-release.md)

Primeira release da linguagem Aipo dentro da fronteira ADP-008: linguagem, runtime, CLI, test runner, C ABI síncrona e thin proofs de interoperabilidade. Engines visuais completos, editores, registry público e profile web amplo permanecem pós-v1.

## Escopo entregue

- Frontend completo, HIR, sema, Core IR, bytecode `.aibc` e Stack VM.
- RegVM experimental com seleção explícita de plano e fallback canônico.
- Backend JavaScript ESM, runtime shim e source maps.
- Backend WebAssembly no subset documentado, com JIT Wasmtime.
- Scheduler cooperativo, async/await, contratos, invariantes e rollback.
- CLI (`run`, `check`, `build`, `test`, `fmt`, `disasm`, `package`, `plan`, `profile`, `debug`, `watch`, `lsp`, `new`, `vendor`).
- C ABI síncrona, handles, capabilities, embedding Rust e harness C.
- Pacotes herméticos, cache offline, vendor e GitHub pinado.
- Host ABI, Poppy, eGUI e game host headless.

## Instalação

Use o arquivo da plataforma publicado na release `v0.1.0`:

```sh
tar -xzf aipo-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
./aipo-v0.1.0-x86_64-unknown-linux-gnu/bin/aipo --version
```

O arquivo inclui `bin/aipo`, `bin/aipo-sh`, `lib/libaipo_c_abi.*`, `include/aipo.h`, README e licença.

## Limites conhecidos

- Wasm e RegVM não têm paridade total; a matriz de backends registra a cobertura medida.
- Fuzz, Miri e ASan não foram executados nesta release.
- Benchmarks são locais e ruidosos; uma matriz de performance dedicada continua pendente.
- A C ABI exige validação de consumidores por plataforma.
- O perfil `embedded` ainda usa `std`; não é no_std/MCU.
