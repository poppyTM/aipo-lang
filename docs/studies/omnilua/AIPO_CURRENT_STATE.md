## 2. Invariantes Arquiteturais e Restrições Vigentes

1. **Pure Rust / Zero Unsafe:**
   - O workspace adota `#![forbid(unsafe_code)]` em todas as crates de produção. Nenhuma melhoria do omniLua baseada em blocos `unsafe` pode ser importada para o núcleo da linguagem sem justificativa excepcional via ADR.
2. **Determinismo Estrito:**
   - Execução mono-thread por runtime (`Value: !Send`). Concorrência é puramente cooperativa no scheduler com relógio virtual.
3. **Tratamento de Falhas (Modelo B+):**
   - Distinção categórica entre `Failure` (recuperável via `attempt { ... }` ou `or_else`) e `Fault` (invariante violado, erro de runtime fatal que interrompe a execução).
4. **Segurança de Host (Deny-by-Default):**
   - Nenhuma operação de IO, tempo ou ambiente pode ocorrer sem que a capability correspondente esteja concedida na criação do runtime.
