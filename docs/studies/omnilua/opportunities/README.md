# Oportunidades de Polinização Cruzada omniLua -> Aipo

Este diretório contém as especificações técnicas detalhadas de cada oportunidade identificada e executada durante o estudo comparativo com o omniLua:

- `AIPO-OMNI-001.md`: Canários de vazamento de memória e alocador de rastreamento (`CountingAllocator`).
- `AIPO-OMNI-002.md`: Orçamento de instruções sticky e ininterceptável.
- `AIPO-OMNI-003.md`: API de embedding em Rust puro baseada em escopo (`AipoEngine::scope`).
- `AIPO-OMNI-004.md`: Tarifação periódica de fuel (interval metering).
- `AIPO-OMNI-005.md`: Janelas de registrador na RegVm (register windowing).
