# Reference-language studies

**Status:** live (methodology) · **Authority:** Level 6 (record) — nothing here redefines
semantics; conclusions become ADP/issue before they become code.
**Prerequisite:** `./studies/fetch-refs.sh` (clones outside the repo, by default in
`~/aipo-refs`).

This round relates inspection of pinned sources to the fixes and to the next proposals. Code
reading is not benchmark results.

## Why it exists

Calibrate `RegVm`, `aipo-wasm` and the embedding profiles against real implementations instead
of reinventing. Rule: **no decision enters the code without an ADP/issue; this directory
records the study, not the decision.**

## Guides and files in this directory

- [Master guide for LLMs](llm-study-guide.md): methodology, limits, corpus and phases.
- [Usage and reimplementation guide](runtime-hardening-guide.md): concrete changes of this
  review.
- [Reference VMs](reference-vms.md): Wren, QuickJS-ng, Lua and LuaJIT (Tier A studies).
- [Reference runtimes](reference-runtimes.md): Luau, Janet, wasm3, WAMR and wasmi (Tier B + C).
- [Lessons for Aipo](lessons-for-aipo.md): actionable synthesis, implemented actions and
  pending proposals.
- [Source manifest](../../studies/refs.json): full SHAs of the nine pinned references.

implementation.
