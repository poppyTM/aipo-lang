## 2. Architectural invariants and current constraints

1. **Pure Rust / Zero Unsafe:**
   - The workspace adopts `#![forbid(unsafe_code)]` in all production crates. No omniLua-inspired improvement based on `unsafe` blocks may be imported into the language core without exceptional justification via ADR.
2. **Strict determinism:**
   - Single-thread execution per runtime (`Value: !Send`). Concurrency is purely cooperative in the scheduler with virtual time.
3. **Failure handling (Model B+):**
   - Categorical distinction between `Failure` (recoverable via `attempt { ... }` or `or_else`) and `Fault` (violated invariant, fatal runtime error that stops execution).
4. **Host security (Deny-by-Default):**
   - No IO, time or environment operation may occur without the corresponding capability being granted at runtime creation.
