# Product specifications (`docs/product/`)

## What is this directory?
Centralizes the strategic product vision, the problems solved, the user profiles served and the
scope delimitations.

## What is it for?
Prevents wasted engineering by ensuring developers and agents understand the *why* of each feature
before implementation.

## Inventory
- `vision.md`: Product vision, value proposition and personas.
- `scope.md`: Scope of the `aipo v0.1.0` release and post-v1 limits.
- `../adp/ADP-008-v0.1.0-language-release.md`: Language-release decisions and Definition of Done.
- `../adp/ADP-009-synchronous-c-abi.md`: C embedding boundary.
- `../adp/ADP-010-interoperability-thin-proofs.md`: Rust/C/JS proof criteria.
