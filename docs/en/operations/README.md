# Operations and infrastructure (`docs/operations/`)

## What is this directory?
Contains runbooks, deployment instructions, observability and disaster-recovery plans.

## What is it for?
Ensures production operation of the software is predictable, auditable and resilient to failures.

## Inventory
- `deployment.md`: Build, packaging and continuous-delivery procedures.
- `observability.md`: Metrics, structured logs and distributed tracing.
