# Security and trust (`docs/security/`)

## What is this directory?
Contains the trust model, risk analysis and the heavy security contract of the project.

## What is it for?
Ensures security is not an afterthought, establishing strict controls against credential
leakage, privilege abuse and supply-chain attacks.

## Inventory
- `threat-model.md`: threat modeling (STRIDE methodology).
- `security-contract.md`: strict code and execution security contract.
- `github-package-fetch.md`: network, cache and integrity policy for public package fetch.
