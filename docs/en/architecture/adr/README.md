# Architectural Decision Records (`docs/architecture/adr/`)

## What is this directory?
Contains the formal, immutable records of significant architectural decisions taken throughout
the project.

## What is it for?
Preserves historical context, the options evaluated, the consequences accepted and the criteria
that justified each structural decision.

## Inventory
- `001-architecture-baseline.md`: Decision establishing the initial architectural boundaries and
  the ports-and-adapters model.
