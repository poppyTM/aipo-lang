# Aipo v0.1.0

**Date:** 2026-10-28 · **Goal:** P07-G03 · **Status:** published as stable

Release: https://github.com/poppyTM/aipo-lang/releases/tag/v0.1.0 · Evidence: [P07-G03](../evidence/P07-G03-release.md)

First release of the Aipo language within the ADP-008 boundary: language, runtime, CLI, test
runner, synchronous C ABI and thin interoperability proofs. Complete visual engines, editors,
public registry and broad web profile remain post-v1.

## Delivered scope

- Complete frontend, HIR, sema, Core IR, `.aibc` bytecode and Stack VM.
- Experimental RegVM with explicit plan selection and canonical fallback.
- JavaScript ESM backend, runtime shim and source maps.
- WebAssembly backend in the documented subset, with JIT Wasmtime.
- Cooperative scheduler, async/await, contracts, invariants and rollback.
- CLI (`run`, `check`, `build`, `test`, `fmt`, `disasm`, `package`, `plan`, `profile`,
  `debug`, `watch`, `lsp`, `new`, `vendor`).
- Synchronous C ABI, handles, capabilities, Rust embedding and C harness.
- Hermetic packages, offline cache, vendor and pinned GitHub.
- Host ABI, Poppy, eGUI and headless game host.

## Installation

Use the platform file published in release `v0.1.0`:

```sh
tar -xzf aipo-v0.1.0-x86_64-unknown-linux-gnu.tar.gz
./aipo-v0.1.0-x86_64-unknown-linux-gnu/bin/aipo --version
```

The archive includes `bin/aipo`, `bin/aipo-sh`, `lib/libaipo_c_abi.*`, `include/aipo.h`,
README and license.

## Known limits

- Wasm and RegVM do not have full parity; the backend matrix records the measured coverage.
- Fuzz, Miri and ASan were not run in this release.
- Benchmarks are local and noisy; a dedicated performance matrix is still pending.
- The C ABI requires per-platform consumer validation.
- The `embedded` profile still uses `std`; it is not no_std/MCU.
